Read this as directional, not conclusive

n=5 (localizable ground truth). The hybrid's MRR gain is real and consistent with genuine complementary signal — BM25 and the chunked embedder disagree about which files matter, and fusion often lands nearer the better of the two, occasionally beating both outright (astropy-14508: rank 1, neither component alone got there).

The cost: Hit@100 drops from 0.833 to 0.667 for both the embedding rerank and the hybrid, versus BM25 alone. Both stages only rerank within BM25's own top-200 candidate pool — RRF fusion can push a file BM25 had correctly in its top-100 further down if the embedder scores it poorly, which is what happened here. This is an inherent cost of the candidate-pool cascade design, not of fusion itself.

This is exactly the opposite finding from the earlier whole-file embedding ceiling test, where embeddings lost badly on every metric. Chunking (AST-based, per function/class) appears to be doing real work — worth a larger manifest run before drawing firm conclusions.
